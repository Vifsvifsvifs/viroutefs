# ViRouteFS 0.14.0-beta.23

Упрощён интерфейс маршрутов, VPNGate и Flow Scanner без изменения базовой модели: root по-прежнему необязателен, а обычный трафик по умолчанию использует System.

- В VPNGate страны показаны понятными названиями, домашняя страна исключается, а предпочтительная страна предлагается только при наличии минимум двух серверов для резерва.
- Автоматический VPNGate остаётся одним управляемым подключением до шести серверов, обновляет каталог при каждом запуске и обслуживает только выбранные приложения.
- Приложение, уже назначенное другому VPN или автоматическому VPNGate, скрывается из остальных VPN-списков; выбранные приложения остаются сверху.
- Списки приложений загружаются вне главного UI-потока и кэшируются безопасно, поэтому страницы маршрутов и сканера открываются быстрее.
- В Flow Scanner добавлена короткая инструкция для новичка и отдельно объяснены необязательные root-снимки.
- Аппаратная кнопка «Назад» возвращает с каждого вложенного root-экрана на предыдущую страницу приложения.
- Ссылка добровольной поддержки теперь открывается также нажатием на видимый адрес; кнопка и локальный QR ведут на тот же HTTPS-адрес. Это поддержка, а не покупка функций.
- Уточнены подписи hosts и блокирующего маршрута: записи hosts уже имеют высший DNS-приоритет, а Block применяется действующим fail-closed runtime.
- Сохранено исправление OpenVPN из beta.22 для старых серверов с сокращённым key-method ответом.

Доступность отдельных добровольческих VPNGate-серверов не гарантируется. Автоматический режим проверяет несколько кандидатов и не направляет через них приложения, которые пользователь не выбирал.
