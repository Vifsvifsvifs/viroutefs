# ViRouteFS 0.14.0-beta.22

Исправлено подключение к старым OpenVPN-серверам с сокращённым ответом key-method.

- Клиент принимает совместимый с OpenVPN 2.5 ответ, который заканчивается после обязательной строки параметров и не содержит необязательных полей сервера.
- TLS-ответы дочитываются как поток с жёстким ограничением размера, а фиксированные поля проверяются полностью.
- Исправление проверено прямым подключением к проблемному серверу: сервер выдал туннельный адрес и DNS.
- Логин, пароль, сертификат и полный профиль в диагностику не выводятся.
