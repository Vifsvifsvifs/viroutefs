# ViRouteFS 0.14.0-beta.10

Исправления OpenVPN и VPNGate, проверенные на пользовательском наборе `.ovpn` + `ca.crt` + `pass.txt`.

- OpenVPN `cipher` в TLS-профилях корректно переносится в `data_ciphers` и `data_ciphers_fallback`, а не в поле режима `static_key`.
- IPv4 `route` из `.ovpn` преобразуются в CIDR-сети OpenVPN endpoint и больше не теряются как неизвестные директивы.
- Добавлен безопасный импорт двухстрочного `auth-user-pass`/`pass.txt`: логин и пароль не выводятся в журнал, исходные байты очищаются.
- VPNGate может загрузить официальный каталог через уже настроенный VLESS/XHTTP-профиль, если прямой доступ к `www.vpngate.net:443` заблокирован сетью.
- У загрузки VPNGate появился общий лимит времени в дополнение к сетевым тайм-аутам.
- Сохранены исправления XHTTP DNS и импорта `.p12/.pfx` из beta.8–beta.9.
