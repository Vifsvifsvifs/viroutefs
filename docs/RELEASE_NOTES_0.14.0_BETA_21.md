# ViRouteFS 0.14.0-beta.21

Исправлена совместимость OpenVPN с серверами, которые делят ответ обмена ключами на несколько TLS-фрагментов.

- Клиент теперь дочитывает ограниченное по размеру сообщение key-method до его структурного завершения.
- Поля фиксированной длины читаются полностью, поэтому неполный TLS-фрагмент больше не принимается за целый ответ.
- Исправление применяется и при последующем обновлении ключей, не меняя маршрутизацию и остальные VPN-профили.
