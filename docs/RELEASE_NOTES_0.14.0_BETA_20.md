# ViRouteFS 0.14.0-beta.20

Диагностическая сборка для точной проверки совместимости OpenVPN 2.5.

- Разделены ошибки отправки OpenVPN key-method, ожидания ответа сервера и разбора ответа.
- Сообщения не содержат логин, пароль, сертификаты или полный профиль.
- Маршрутизация, VPNGate и остальные протоколы не изменены.
