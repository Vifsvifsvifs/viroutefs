# ViRouteFS 0.14.0-beta.9

Небольшое исправление совместимости импорта OpenVPN PKCS#12 после beta.8.

- Системный выбор файла теперь показывает `.p12` и `.pfx` даже на прошивках, которые скрывают их при стандартном MIME-фильтре PKCS#12.
- Выбранный файл по-прежнему строго проверяется внутри ViRouteFS: случайный или повреждённый документ не импортируется.
- Пароль контейнера используется только во время локального открытия и сразу очищается; в профиль он не сохраняется.
- Сохранены исправление DNS для Xray/XHTTP и весь функционал beta.8.
